

Tablet nodes — это ноды, которые обслуживают динамические таблицы YT (аналог key-value БД поверх YT). Они держат в памяти таблеты (шарды таблицы), принимают чтения/записи, пишут в журнал изменений и периодически сбрасывают
   данные в чанки, которые уже хранят data nodes.

Data nodes — это «диски» кластера: они физически хранят чанки на локальных дисках и отдают/принимают байты. Чанк — это immutable-кусок данных (обычно сотни МБ), и всё, что лежит в YT — статические таблицы, файлы, журналы,
  сброшенные данные динамических таблиц — в итоге лежит как чанки на data nodes. Мастер знает только «чанк X лежит на нодах A, B, C», а сами байты читаются/пишутся уже напрямую с data nodes.

Stateless = прокси ничего не помнит между запросами. Обработала запрос — забыла. Всё важное хранится в других компонентах (мастер и т.д.), а прокси просто перекладывает запросы туда.
